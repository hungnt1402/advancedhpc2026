\section{Implementation}
I applied a $7\times7$ Gaussian filter to the grayscale image. The coefficients sum to 1003. One kernel reads the filter from global memory; the other copies its 49 coefficients into shared memory before convolution. Both preserve the three-pixel border.

I ran the notebook on Google Colab with a Tesla T4 and a $256\times256$ sample image.
GPU timings use \texttt{time.time()} after warm-up and synchronization, averaged over three runs; allocation and image transfers are excluded. Where measured, CPU time is one run; speedup is relative to that Python CPU implementation.

\section{Discussion}
The $16\times16$ block gave the best time for both versions. Shared filter memory was slightly slower for every tested block. Its loading and synchronization overhead may outweigh its benefit on this small image.
